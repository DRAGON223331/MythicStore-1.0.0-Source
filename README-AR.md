# MythicStore 1.0.0 — متجر GawharaSMP الخاص

إضافة Paper مستقلة باسم **MythicStore**، مصممة للعمل مع إضافة **GawharaItems 1.3.1** الموجودة في مشروع GawharaSMP.

## محتويات المتجر

- 9 Bundles كاملة، كلها في صفحة واحدة على هيئة شبكة 3×3 وبترتيب السعر من الأقل للأعلى.
- كل Bundle يعطي 4 قطع الدرع + السلاح الخاص بالطقم + معول الطقم، عن طريق أمر GawharaItems الرسمي.
- صفحة منفصلة للسيوف والأسلحة المخصصة: السيوف العنصرية، أسلحة الأطقم، الفأس الملكي، هراوة الديمون، المطرقة، الرمح والنشّاب.
- صفحة منفصلة للمعاول والفؤوس: Miner Pickaxe وLumber Axe ومعاول الأطقم التسعة.
- اختيار كمية قبل الشراء (1 إلى 4) مع حساب الإجمالي.
- فحص الخانات الفارغة قبل خصم الأموال.
- الأسعار للشراء فقط؛ لا يوجد Sell لتجنب إعادة تدوير العناصر النادرة وتحويلها إلى مصدر تضخم.

## المتطلبات

- Paper متوافق مع API 26.3 / Java 25.
- `GawharaItems` إصدار 1.3.1 أو أحدث، ويجب أن يعمل أمر `/gitems give` و`/gitems bundle`.
- Vault.
- إضافة اقتصاد تسجل Vault Economy provider، مثل EssentialsX Economy أو CMI Economy.
- لتظهر أيقونات الأدوات المخصصة، يجب أن يكون Resource Pack الخاص بـ GawharaItems مفعلًا عند اللاعب.

## التثبيت

1. ضع `MythicStore-1.0.0.jar` في مجلد `plugins`.
2. تأكد أن `GawharaItems` وVault وإضافة الاقتصاد موجودة.
3. أعد تشغيل السيرفر.
4. افتح المتجر باستخدام `/mythicstore` أو `/mstore`.

## الأوامر والصلاحيات

- `/mythicstore` أو `/mstore`: فتح المتجر — `mythicstore.use` (افتراضيًا للجميع).
- `/mythicstore reload`: إعادة تحميل الأسعار — `mythicstore.admin` (افتراضيًا OP).

## تعديل الأسعار

بعد التشغيل سيُنشأ `plugins/MythicStore/config.yml`. عدّل الأسعار تحت:

- `prices.bundles`
- `prices.items`

ثم نفّذ `/mythicstore reload`. الإضافة تفرض حدًا أدنى 300,000 وحدًا أقصى 1,000,000 حتى لا يخرج المتجر عن التصميم المطلوب.

## البناء

المصدر يحتاج JDK 25. أسهل طريقة هي رفع المجلد إلى GitHub ثم فتح تبويب **Actions** وتشغيل **Build MythicStore**. سيظهر `MythicStore-1.0.0.jar` كـ Artifact بعد اكتمال البناء.

> ملاحظة تقنية: المتجر يستخدم Vault للاقتصاد، ويستدعي أوامر `/gitems give` و`/gitems bundle` من Console حتى يسلّم نفس العناصر الحقيقية ذات الـPDC والـItem Models؛ لا ينشئ نسخًا شكلية من العناصر.
